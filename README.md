# egfwp4500-recharge-fusion-v4t9

Implementation accompanying the manuscript:

**"Multi-Sensor Satellite Fusion for Groundwater Recharge Estimation"**
James Thomas, Daniel Mensah, Tomaz Kovac.
*Remote Sensing of Environment*, 2024.

The repository contains the latent-variable fusion model and the GRACE-FO /
Sentinel-2 preprocessing chain. Release v1.0.1 is the research build. The public
announcement of this repository is embargoed by the lab release committee until
the journal's media embargo lifts; do not link it publicly before clearance.
